# Playtest build d211613 (2026-10-29)

Protocol 39. Release: https://github.com/Yeezima/sm-reimpl-releases/releases/tag/tester-2026-10-29-d211613

- Custom shoulder images: the badge screen now lists what images it accepts (PNG, JPG, WebP, BMP or TGA, at most 4096 x 4096 pixels and 8 MB). An image that is refused now says why, with its size and the limit.
- Customizer, whole armour sets: the Salamanders Veteran set now shows its chest armour and the Emperor's Children set its backpack. The cloth tabards, loincloths and furs of the Battle-Damaged, Master-Crafted, Veteran, Black Templars, Space Wolves and Salamanders armour now show too (for now they hang stiff and do not sway).

### Hosting and bots
- Hosting a match no longer starts bots on its own. To play against bots, set BOTS with - and + (1 to 15) before you press HOST A MATCH; they split over the two sides. Each bot needs about 0.65 GB of memory, so on a PC with 8 GB keep to a few. To change the number, stop the server and host again.
- "3 - Host a match on this PC" no longer starts 7 bots: it starts an empty server. Use HOST A MATCH in "2 - Play" for bots.
- Bots now write their own log files (in the logs\bots folder next to your log), so your own log is never pushed out by them. Please keep attaching %APPDATA%\sm-reimpl\logs\godot.log to bug reports.
- If the game closes right after it starts, a window now says so and where its log is, so you can send it with your report.
