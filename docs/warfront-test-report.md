# Warfront: test report (W17)

State checked: branch `claude/warfront-w17`, which is `claude/warfront` at 9218dbbb (`WarfrontRules.Version` 13) plus the W17 commits (test aids, the proof script, docs).
Date 2026-11-17. Machine: one Windows PC, loopback only (127.0.0.1); every server and client was started and stopped by PID by `tools/warfront-proof.ps1`
(one switch per run, each run time-bounded). Logs, `run.json` copies, stills and clips are in `<media folder>\warfront\w17\<run>\` (never in the repository); each run
writes a `summary.txt` whose `AIDED:` lines name every test aid that stood in for play. **Nothing aided is reported as played.**

Aids used (all test-only, loopback-only, listed in `docs/commands.md`): `SM_WF_START` (start fronts), `SM_WF_ROLLS` (forced rolls), `SM_WF_RESOLVE=win|wipe` (the battle ends 5 s in),
`SM_TFW_WIN_TEST=<m>` (enemies near the human fall: the fighting is left out), `SM_TFW_KEEP_HUMAN=1` (a fallen human stands up), `SM_WF_LANE_WALK=<s>` **(new in W17: the
leader is put on the next open objective; captures stay on the real rules)**, `SM_WF_FORTRESS_WALK=<s>`, `SM_WF_FALL_TEST=<s>`, `SM_WF_ROSTERS=<n>` **(new in W17: rosters recruited to n)**,
`--warfront-bot-pick first|last` **(new in W17: the test bot deploys the last offered target)**, and editing `run.json` into the breakthrough state (named where used).
A real bot cannot capture objectives without the walk aid (the co-op bot engages every Ork within 150 m and never walks on, measured with 1500 Orks shown): **a bot or human
capturing objectives with no aid is unproven.**
