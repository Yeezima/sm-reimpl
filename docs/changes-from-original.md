# Changes from the original

The goal is faithfulness to *Warhammer 40,000: Space Marine* (2011) multiplayer. This file lists every known difference, so anyone can see what is the same and what is not; `spec/behavior.md` keeps the full parameter records (value, units, source, confidence).
Keep it current: every deliberate change and every "ours" rule gets a row here when it is added, and a row moves out when evidence replaces our choice.

Everything not listed here follows the original or the original's data as read from the player's install. There is no list of "confirmed the same".

Spec section names below are the headings in `spec/behavior.md`.

## 0. Added content (not in SM1; off with `--content faithful`)
