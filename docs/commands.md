godot.cmd [--windowed] [--background] [--log f] [--exe p] [--build] [<engine args>] -- <client args> :: tools/no-focus-steal (owner, 2026-10-31): THE way tests and agents start Godot. Headless by default (adds --headless and --path client; Godot's console wrapper with CREATE_NO_WINDOW, so neither it nor its real Godot child ever shows a console; output into the log, copied to the console; exit code is Godot's). --windowed (screenshots, recordings, the perk-card shot): a real rendering window on the private desktop sm-reimpl-test (CreateDesktop), never on the owner's screen, never the foreground, no mouse or keyboard; adds --test-window. --background returns at once with the pid and log (stop it: taskkill /PID <pid> /T /F). --exe runs an exported game (sm-reimpl.console.exe) the same way. Never run & ..._console.exe or the Godot exe directly from a shell: a direct windowed start is shown at the primary screen's top-left and takes the foreground before any game code runs (Godot clamps --position into a screen). client.cmd with --bot now runs through godot.cmd (headless), with --test-window through godot.cmd --windowed. A capture (--screenshot, --screenshot-every, a movie) draws nothing headless: it needs `godot.cmd --windowed` or `--test-window` among the client args; `client.cmd --bot` alone is headless now; --on-desktop (stripped) keeps the old visible window for a bot someone wants to watch

## Controller (gamepad)

Plug a pad in (or press a button on one already connected) and it becomes the way you play; touch a key, click or move the mouse and the keyboard and mouse are back; unplug it and they are back too (no restart). The layout is the original's Xbox 360 one:
left stick move; right stick look; LT aim; RT fire; LB grenade; RB reload / vent; X strike; Y stun / alt strike (the left stick forward when you press it: the charge); B use; A evade / jump pack; D-pad weapon swap (up pistol, right primary, down second
primary); hold the left stick click to sprint; click the right stick to cycle the scope zoom; Start the game menu (the loadout picker, resume, leave); Back the scoreboard. Menus: the D-pad or the left stick moves the focus, A accepts, B goes back; the first press with nothing focused
focuses the first control. The table with every row's source is spec "Controller (gamepad)" (`client/Gamepad/GamepadRules.cs`). Tests: `dotnet test --filter GamepadTests`, and the `--pad-test` run above.
